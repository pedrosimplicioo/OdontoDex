# Vídeo da landing de tráfego pago

O arquivo `demonstracao-odontodex.mp4` é a versão otimizada para web da gravação original.

- H.264/MP4
- 720 × 1454 px
- 30 fps
- sem faixa de áudio
- reprodução automática, em loop, sem controles e com `playsinline`

A gravação original permanece intacta fora do projeto.
